# Aura Electronics

Build a modern, production-quality Electronics Store E-Commerce Website using only HTML, CSS, and Vanilla JavaScript. The backend will be integrated with Firebase later, so the frontend must be clean, modular, scalable, and backend-ready.

GENERAL REQUIREMENTS

- Use only HTML, CSS, and JavaScript.

- Do NOT use React, Vue, Angular, Bootstrap, jQuery, or other frameworks.

- Write clean, reusable, modular code.

- Avoid duplicate code completely.

- Mobile-first responsive design.

- Modern premium UI inspired by Apple Store, Samsung Store, Best Buy, and Amazon.

- Smooth animations and transitions.

- Professional folder structure.

- Every feature should be easy to connect with Firebase Authentication, Firestore, and Firebase Storage later.

- Maintain a single source of truth for application state.

- Use reusable utility functions and service layers.

- Never break existing functionality when adding new features.

FIREBASE READY

==================================================

Structure every JavaScript feature so it can easily connect later to:

- Firebase Authentication

- Firestore Database

- Firebase Storage

- Firebase Hosting

Separate UI from business logic. Place all future CRUD operations inside reusable service functions. Avoid hardcoding data throughout the application.

==================================================

FINAL GOAL

==================================================

Develop a fully responsive, enterprise-level Electronics Store website with separate Customer and Admin panels. The code must be production-ready, modular, reusable, scalable, easy to maintain, free from duplicate code, and designed for seamless future Firebase integration without requiring major refactoring.
